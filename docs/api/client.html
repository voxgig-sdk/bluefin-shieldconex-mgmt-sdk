create

POST /clients

Operation ID: create-client.

Authentication: basic token (basic).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | name | query | string | Yes | The name of the client. | | billingId | query | string | No | Billing identifier associated with the client. | | mid | query | string | No | Merchant ID associated with the client. | | isActive | query | boolean | Yes | Indicates if the client is active. | | directPartner.id | query | integer (int32) | Yes | Identifier of the direct partner associated with the client. | | directPartner.name | query | string | Yes | Name of the direct partner associated with the client. | | contact.userName | query | string | Yes | Username of the primary contact. | | contact.firstName | query | string | Yes | First name of the primary contact. | | contact.lastName | query | string | Yes | Last name of the primary contact. | | contact.email | query | string (email) | Yes | Email address of the primary contact. | | contact.phone | query | string | Yes | Phone number of the primary contact. | | contact.userRole | query | enum: Partner Supervisor | Yes | Role of the primary contact within the organization. | | contact.isActive | query | boolean | Yes | Indicates if the primary contact is active. | | contact.sendWelcomeEmail | query | boolean | Yes | Indicates if a welcome email should be sent to the contact. |
