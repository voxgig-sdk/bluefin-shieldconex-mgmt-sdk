Operation ID: list-transactions.

Authentication: basic token (basic).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | transactionType | query | enum: 4, 5, 6 | No | Transaction Type. Detokenization = 4, Tokenization = 5, 3DS = 6, Other = empty | | partner | query | string | No | Filter the list by Partner. The parameter value can be either a Partner ID or Name. | | client | query | string | No | Filter the list by Client. The parameter value can be either a Client ID or Name. | | success | query | enum: true, false | No | Filter the list by success indicator. | | dateFrom | query | string (date-time) | No | Filter the list by transaction date. Only show transactions that were processed after this date. | | dateTo | query | string (date-time) | No | Filter the list by transaction date. Only show transactions that were processed before this date. | | messageId | query | string | No | Filter the list by Message ID. | | reference | query | string | No | Filter the list by Reference ID. | | take | query | integer (int32) | No | The number of entries to include in the list. | | skip | query | integer (int32) | No | The number of results to skip before listing entries. | | paging.mode | query | enum: nocount, full | No | Toggles the total count in the response. |
